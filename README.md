# Contact Manager — Frontend

React frontend for the Contact Manager app.

**Live:** https://contact-manager-mern-frontend.vercel.app

**Backend repo:** https://github.com/Armaan2022/Contact-Manager-MERN-Backend

## Tech Stack

- React 18
- React Router v6
- React Bootstrap
- React Toastify

## Features

- User registration and login
- Create, edit, and delete contacts
- Search contacts by name
- JWT-based session management

## Local Setup

```bash
git clone https://github.com/Armaan2022/Contact-Manager-MERN-Frontend.git
cd Contact-Manager-MERN-Frontend
npm install
```

Create a `.env` file:

```
REACT_APP_API_URL=http://localhost:5000
```

```bash
npm start
```

App runs on http://localhost:3000
